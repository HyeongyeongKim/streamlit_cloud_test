# 오늘의 정원 — 나의 속도로 이어가는 일정 관리

배포 주소: https://codeithyeongyeong.streamlit.app/

## 실행 및 배포

- GitHub 저장소: HyeongyeongKim/streamlit_cloud_test
- 브랜치: main
- Streamlit Community Cloud 엔트리: streamlit_cloud.py
- Python 3.11 이상 권장

```sh
pip install -r requirements.txt
streamlit run streamlit_cloud.py
```

GitHub에 푸시하면 이 저장소에 연결된 기존 Streamlit 앱이 변경사항을 반영합니다.

## 구조

화면은 Python/Streamlit입니다. 회원 인증, 계정별 일정·일기·습관, 사진, 공유 반응은 기존 오늘의 정원 HTTPS API를 호출합니다. 데이터는 기존 서버의 D1/R2에 저장되므로 Streamlit 재시작 시 사라지지 않습니다. 기존 이메일 계정도 사용할 수 있습니다. Sites의 기존 백엔드를 삭제하면 저장 기능이 중단됩니다.

기본 API: https://oneul-garden.hyeongyeong.chatgpt.site

서버 이전 시 환경변수 GARDEN_API_URL로 변경할 수 있습니다. API 세션은 방문자별 st.session_state에 보관하며 전역 캐시로 공유하지 않습니다. 브라우저 새로고침 후 재로그인이 필요할 수 있습니다. 비밀번호 재설정 메일과 이메일 소유 확인 메일은 아직 연결하지 않았습니다.

## 기능과 화면

- **오늘 · 일정**: 오전·오후·밤·오늘 중의 네 영역. 시각 없이 시간대만 정하거나 시작/종료 시각을 선택합니다. 정확한 시각을 입력하면 해당 시간대로 분류합니다.
- **계획과 실제 기록**: 예정 시각과 실제 활동 시각을 따로 남깁니다. 완료·조금 진행·안 하기로 결정·쉬어 간 일 상태를 제공합니다.
- **오늘 줄이기**: 고른 예정 일정을 다른 날짜로 옮깁니다. 시간이 고정된 약속과 이미 실천한 기록은 제외합니다. 전체 완료율이나 연속 기록 압박을 주지 않습니다.
- **내 기록**: 날짜별 일정과 일기, 월간 기록을 돌아봅니다. 기존 일정은 오늘 중으로 표시합니다.
- **함께**: 회원이 공유한 일정·일기에 텍스트 응원을 보냅니다. 공유 여부와 시간 공개 여부를 별도로 선택합니다. 친구 팔로우 기능은 아직 없습니다.
- **일기·습관**: 기존 사진·감정·글 일기와 반복 요일 체크 기능을 유지합니다.
- **화면 설정**: 매트한 추천 팔레트 5종, 배경·글씨·카드·강조 영역·버튼 색상, 한국어 글꼴 3종. 미리 보기와 계정별 저장을 지원합니다. 글꼴은 Google Fonts로 불러오며 연결이 안 되면 기본 sans-serif로 표시됩니다.
- 이메일 회원가입·로그인·로그아웃·비밀번호 확인 후 탈퇴.
- 이모티콘을 앱의 문구·상태·반응 버튼에서 제거했습니다. 과거 반응을 유지하기 위해 API 식별자는 그대로 사용합니다.

일정은 특정 날짜에 해야 하는 일, 습관은 선택한 요일마다 쌓는 실천 기록으로 구분합니다. 기록은 기본 비공개이며 공유를 선택한 항목만 다른 회원에게 노출됩니다.

## 이번 개편의 배포 상태

현재 변경은 로컬 구현 및 검증을 마친 상태입니다. 운영 Streamlit 및 Sites API에는 아직 배포되지 않았습니다.
시간대와 실제 기록은 백엔드 migration 및 API 배포가 필요합니다. 변경 패치와 순서는
[backend_changes/README.md](backend_changes/README.md)에 있습니다. 백엔드가 `schedule-v1` 지원을
알리기 전에는 기존 일정 관리만 사용할 수 있으며, 새 필드가 저장된 것처럼 표시하지 않습니다.

## 검증

```sh
python -m unittest discover -s tests -v
```

Streamlit AppTest로 모든 메뉴와 일정 추가·수정·진행 기록·오늘 줄이기·테마 저장·반응·기존 서버 호환을 검사합니다.
`tests/integration_schedule.py`는 로컬 저장 서버에서만 실행하는 별도 통합 검사입니다.
